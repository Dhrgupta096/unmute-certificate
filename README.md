# 🎙️ UNMUTE • Certificate Studio
### Dayananda Sagar University • Literary Society

An interactive certificate design and generation studio created for **UNMUTE** — the annual open mic event organized by the Literary Society at Dayananda Sagar University.

Inspired by retro collectible documents, this project offers two custom certificate aesthetics that reject generic certificate templates in favor of authentic, memorable design.

---

## 🎨 Templates

### 1. The Passport to Expression (*Olivia Rodrigo Vintage Passport Homage*)
- Dual-fold passport booklet with authentic perforated seam.
- Deep vintage royal purple star-studded perimeter frame (`★ ★ ★ ★`).
- Halftone performer portrait with violet duotone screen.
- Official rubber stamp: `DSU LIT SOC • UNMUTED • STAGE ACCESS`.
- Monospaced governmental data matrix (Name, Voice/Art, Event, Stage ID, Status).
- International Machine Readable Zone (MRZ) formatted with performer credentials.
- Dual authorized signatures with institutional crests.

### 2. The Creative License (*Bureaucratic Stage Accreditation*)
- Realistic 3D metallic paperclip pinned to the top card margin.
- Crimson typewriter serial number: `# OF LICENSE 2212`.
- Industrial grotesque typography: `CREATIVE LICENSE` with micro-manifesto.
- Polaroid performer photo framed with `★ DSU LIT SOC • UNMUTE` badge.
- Overlapping royal blue rubber ink seal: `DAYANANDA SAGAR UNIV • LIT SOC • STAGE VERIFIED`.
- Red ink stamp badge: `100% RAW VOICE`.
- Bureaucratic form grid, middle genre ribbon, and high-density vector barcode.

## 🚀 How to Use

1. Double-click or open `index.html` in any web browser:
   ```bash
   open index.html
   ```
2. **Switch Templates:** Toggle between **The Passport** and **The Creative License**.
3. **Customize Details:** Edit performer name, category, distinction, ID number, and dates using the sidebar or by **clicking directly on any text on the certificate**.
4. **Performer Photo:** Upload any photo or select from sample presets. Toggle between 4 vintage photo filters (Purple Tint, B&W 35mm Film, Vintage Sepia, Normal).
5. **Export:**
   - Click **Print / PDF** to print or save via browser print dialog.
   - Click **Download High-Res** to export a 300 DPI PNG file directly.
